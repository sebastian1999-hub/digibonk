# Digibonk 1.11.1

- M abre y cierra el mapa ampliado. La partida se pausa mientras está abierto.
- Al cerrar el mapa se recupera el estado previo: una partida que ya estaba pausada sigue en pausa.
- El atajo del mapa se puede cambiar en Ajustes de controles.

Abre **Digibonk.exe** para actualizar. Las partidas y los ajustes se conservan.
