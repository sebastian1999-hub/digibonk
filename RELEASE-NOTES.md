# Digibonk 1.9.0

- Barra progresiva de recarga de habilidad bajo el personaje y en su panel.
- Retirado el cuadro informativo del lado izquierdo.
- Nuevo lanzador con actualizaciones automáticas desde GitHub Releases.
- Conserva partidas, ajustes, cuenta de Supabase y récords.
- Si no hay conexión o falla una actualización, usa la versión instalada.

Para instalar: descarga el ZIP **Digibonk-PC-1.9.0.zip**, extrae todos los archivos y abre **Digibonk.exe**. Los jugadores que aún usan 1.8.0 o anterior deben instalar este ZIP una vez para disponer del actualizador.
