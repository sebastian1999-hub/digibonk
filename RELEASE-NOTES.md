# Digibonk 1.11.4

- Enemigos normales en grupos de 3 a 6, con menos vida y daño individual; las hordas crecen con el tiempo.
- Oleadas de portales mucho más numerosas, con refuerzos mayores y presión según el nivel de entrada.
- Mayor proporción de enemigos de cuerpo a cuerpo para que las hordas no se conviertan en muros de proyectiles.
- Separación entre enemigos cercanos para que las hordas se distingan y no se superpongan en un único punto.
- Recompensas individuales ajustadas a la nueva densidad; se mantienen los límites de entidades.
- Eliminado el mensaje inferior de la pantalla de carga.

Abre **Digibonk.exe** para actualizar.
